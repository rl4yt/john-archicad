# John para Archicad — L4 Engenharia

O John opera o Archicad (25 a 29) pelo Claude: lê o modelo, tira quantitativos e cria paredes, lajes, portas, cotas e mais.

## Instalar

1. Baixe o instalador: **[JohnSetup-Archicad.exe](https://github.com/rl4yt/john-archicad/releases/latest/download/JohnSetup-Archicad.exe)**
2. Execute. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Quando pedir, cole a sua chave `JOHN-XXXX-XXXX-XXXX` (precisa de internet).
4. Abra o Archicad com um projeto e o Claude Desktop; na aba Code peça: "John, testa a conexão com o Archicad".

A chave é individual e fica presa ao computador onde foi ativada. Para trocar de PC ou comprar uma chave, fale com a L4 Engenharia: [WhatsApp +55 73 99817-4140](https://wa.me/5573998174140).

O add-on é baseado no [Tapir](https://github.com/ENZYME-APD/tapir-archicad-automation) (licença MIT, incluída no instalador).
